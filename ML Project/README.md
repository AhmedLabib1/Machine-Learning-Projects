# 📊 Regression and Classification Models - Assignment 1

This project demonstrates the application of various **regression** and **classification** techniques using real-world datasets. The models are built, trained, and evaluated using Python libraries such as `pandas`, `scikit-learn`, `matplotlib`, and `seaborn`.

---

## 🧠 Objective

To implement and compare:
- **Simple Linear Regression**
- **Multiple Linear Regression**
- **Polynomial Regression**
- **Logistic Regression**

Using proper **EDA**, **data preprocessing**, **model evaluation**, and **visualization**.

---

## 📊 Datasets Used

- **Regression Dataset**: *Car Prices*
- **Classification Dataset**: *Titanic*

> Both datasets were sourced from Kaggle or UCI Machine Learning Repository.

---

## ✅ Tasks Covered

### 🔷 Regression Models
- Performed EDA and preprocessing
- Built and evaluated:
  - Simple Linear Regression
  - Multiple Linear Regression
  - Polynomial Regression (degrees 2, 3, and 4)

### 🔷 Classification Model
- Preprocessed and encoded features
- Trained and evaluated:
  - Logistic Regression
  - Confusion Matrix visualization
